# Benchmark data

The five files of the type-nn board, copied from
https://github.com/hadilq/type-nn/tree/main/data, plus `digits.csv.gz` for
`benchmarks/scale.py`:

| file              | source                                                             | license   |
| ----------------- | ------------------------------------------------------------------ | --------- |
| `iris.data`       | UCI Machine Learning Repository, Iris (Fisher, 1936)               | CC BY 4.0 |
| `wine.data`       | UCI Machine Learning Repository, Wine (Aeberhard & Forina, 1991)   | CC BY 4.0 |
| `wdbc.data`       | UCI, Breast Cancer Wisconsin (Diagnostic) (Wolberg et al., 1995)   | CC BY 4.0 |
| `ionosphere.data` | UCI, Ionosphere (Sigillito et al., 1989)                           | CC BY 4.0 |
| `digits.csv.gz`   | UCI Optical Recognition of Handwritten Digits (Alpaydin & Kaynak, 1998), the 1797-sample 8x8 test set as shipped in scikit-learn (`sklearn/datasets/data/digits.csv.gz`) | CC BY 4.0 |
| `diabetes.tab.txt`| Efron, Hastie, Johnstone & Tibshirani (2004), "Least Angle Regression", via NCSU | public research data |

They are not part of the PyPI package.
